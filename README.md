# ☕ Ngopi Meter

Aplikasi konsol berbasis C++ untuk mengukur jumlah konsumsi kopi harian.

## 🚀 Fitur Utama

- **Sistem Akun:** Registrasi dan login pengguna berbasis memori sementara.
- **Hitung Cangkir Kopi:** Menentukan tingkat fokus berdasarkan jumlah kopi yang dikonsumsi.
- **Kalkulator Efek Kafein:** Menghitung durasi efek sadar normal dan total.
- **Tingkat Produktivitas:** Evaluasi tingkat produktivitas harian.

## 🛠️ Prasyarat

Sebelum menjalankan program ini, pastikan sistem kamu sudah terpasang:

- **Compiler C++** (GCC / MinGW v11.0+)
- **Terminal / Command Prompt** (Windows)

## 📦 Cara Menginstal dan Menjalankan

1. **Clone repository ini:**
    ```bash
    git clone [https://github.com/AmmarLabs/ngopi-meter.git] (https://github.com/AmmarLabs/ngopi-meter.git)
    cd ngopi-meter
2. **Kompilasi kode program:**
    ```bash
    g++ main.cpp
3. **Jalankan program:**
    ```bash
    ./a
